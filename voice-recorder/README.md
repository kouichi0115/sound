# コエメモ（文字起こしボイスレコーダー）

録音した音声をタイムスタンプ付きで文字起こしし、要約してドキュメントとして書き出せる Web アプリです。ビルド不要で、`voice-recorder/index.html` を HTTPS（または localhost）で開くだけで動きます。

## できること

- **録音**: 録音・一時停止・停止、音量メーター表示。音声ファイル（mp3 / m4a / wav / 動画など）の読み込みも可能
- **文字起こし（2種類）**
  - リアルタイム: 録音中にブラウザの音声認識で文字起こし（Chrome / Safari など）
  - 高精度: Whisper をブラウザ内で実行（音声は外部に送信されません。初回のみモデルをダウンロード）
- **タイムスタンプ**: 各発言に時刻が付き、クリックするとその位置から再生。本文はその場で手直し可能
- **要約**: 会議・講義・インタビュー・メモの形式で要約。各要点に根拠の時刻付き
  - ⚙ 設定で Claude API キーを入れると AI 要約（Claude Opus 5.5）
  - キーなしでも端末内の簡易要約が使えます
- **書き出し**: Word（.doc）、Markdown、テキスト、字幕（.srt）、印刷 / PDF、元の音声ファイル
- **保存**: 録音・文字起こし・要約はブラウザ内（IndexedDB）に保存

## メモ

- マイクを使うため、`https://` か `http://localhost` で開いてください（例: `python3 -m http.server` → http://localhost:8000/voice-recorder/）。GitHub Pages でもそのまま動きます。
- API キーはその端末のブラウザにだけ保存され、要約時に Anthropic API へ直接送られます。共有端末では入力しないでください。
